Difu'sBisProRoute 1.0.11 - WoW Forever (Warrior Prot / Fury, Warlock Affli / Demo / Destro)
=========================================================================================

INSTALL
1. Close the game (or stay on the character select screen).
2. Unzip this file.
3. Copy the "DifusBisProRoute" folder into:
   C:\Program Files\World of Warcraft\_forever_\Interface\AddOns\
   (it must end up as ...\AddOns\DifusBisProRoute\DifusBisProRoute.toc, with no nested folders)
4. Start the game. If the addon does not show up, enable "Load out of date AddOns" in the AddOns list.

USAGE
/difu                 open / close the window
/difu spec prot|fury  (Warrior)  ·  /difu spec aff|demo|destro  (Warlock)
/difu sim             WoWSims link for your set (copy it and paste it in your browser)
/difu web             web guide: https://difusbisproroute.github.io/
/difu talents         show which talents the addon reads
/difu export | import sync with the web guide
/difu lang en|es      language
/difu scale 0.6-1.4   window size
/difu reset           reset this character's progress

The addon is free. Source code and updates:
https://github.com/DifusBisProRoute/difusbisproroute.github.io
